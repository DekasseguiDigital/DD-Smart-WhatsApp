# DD Smart WhatsApp Roadmap

## v2.1 Free

DD Smart WhatsApp v2.1 Free completes the transition from a WhatsApp button plugin to a lightweight conversion toolkit for WordPress.

Included in v2.1 Free:

- Smart Floating Actions as an optional module.
- Vertical and Compact List hub layouts.
- WhatsApp Smart Copy action.
- Basic actions for phone, email, social links, maps, booking, form and custom links.
- Basic per-action local analytics.
- WordPress Dashboard analytics widget.
- Internationalized admin, frontend and JavaScript strings.
- Safe schema migration for action metadata.

Floating Actions remains disabled by default so existing installations keep their current behavior after updating.

Radial hub layout is intentionally not shipped in v2.1 Free. It remains a future enhancement pending accessibility, responsiveness and stability validation.

## Maintenance Line

Future free releases may focus on:

- WordPress compatibility.
- PHP compatibility.
- Security fixes.
- Accessibility refinements.
- Bug fixes.
- Translation updates.
- Performance improvements.

## Future PRO Line

The public Free package does not include PRO code, licensing, checkout, license activation or calls to Dekassegui Digital servers.

Possible future PRO modules are documented only as product direction:

- Conditional display rules by page, language, device, schedule or country.
- Advanced analytics.
- GA4, Matomo and Meta Pixel integrations.
- Webhooks and automations.
- Advanced multi-hub rules.
- White label settings.
- AI-assisted WhatsApp message suggestions by page context.

These items are not implemented in v2.1 Free.
